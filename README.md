# Sucata Docs

This is the documentation webpage of
[Sucata](https://github.com/sucata-engine/sucata-engine), a 2D game engine made with Odin and Lua.

It's available on [sucata.dev](https://sucata.dev), and built with [mkdocs](https://www.mkdocs.org/).

## Related

- [sucata-engine](https://github.com/sucata-engine/sucata-engine) — installer and top-level project info
- [sucata-cli](https://github.com/sucata-engine/sucata-cli) — the `sucata` command-line tool
- [sucata-player](https://github.com/sucata-engine/sucata-player) — the engine runtime
